# RA Contact – AI-Powered Interactive Web Game 🌌

> ⚠️ Status: In Progress — 7th Density level under active development

## About
An interactive consciousness journey game inspired by the Law of One. 
Players progress through 7 densities guided by Ra, an AI entity 
powered by Google Gemini. The final density uses real-time hand 
gesture detection via TensorFlow.js and MediaPipe.

## Tech Stack
- Frontend: HTML5, CSS3, Vanilla JavaScript
- Backend: Node.js (no framework)
- AI: Google Gemini 2.5 Flash API
- ML: TensorFlow.js + MediaPipe Hands (gesture detection)

## Features
- 7-level consciousness progression system
- AI-driven real-time conversations with "Ra" (Gemini API)
- Dynamic scoring / vibration system
- Hand gesture detection for final level (ML in the browser)
- Particle animations, typewriter effects, immersive UI

## Setup (Local)
1. Clone the repo
2. Run `npm install`
3. Create a `.env` file: `GEMINI_API_KEY=your_key_here`
4. Run `node server.js`
5. Open `http://localhost:3000`
